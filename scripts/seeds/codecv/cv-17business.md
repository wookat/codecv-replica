**技术栈**： `TypeScript` `Vue3.x` `markdown-transform-html` `Vite`
**项目简介**：该项目是一款 Markdown 简历制作工具，支持markdown模式和所见即所得两种编辑模式，排版完全自定义.
**线上地址**：[https://codeleilei.gitee.io/markdown2pdf](https://codeleilei.gitee.io/markdown2pdf)
**主要功能**：
1. 基于 Markdown 的书写方式，简单易上手，且支持左右布局，编写一套 Markdown 可适配所有模版

2. 根据自身喜好DIY简历样式、字体，且提供实时分页预览，可根据比例调整 PDF 预览大小

3. 智能自动一页，简历内容不足或过多时，可通过动态计算后自动进行均匀拉伸或收缩

4. 动态调节简历元素中的边距问题，可扩展性高

**项目难点**：
- 从 0 到 1 **设计所见即所得编辑器**，并解决两种编辑模式之间需要做到数据同步的问题
- 解决原生 Markdown 语法并不支持左右布局，图标等语法的问题
- 解决预览 A4 纸效果会出现的**边界内容截断**，以及导出 PDF 效果在各系统**显示不一致**的问题
